# Химчистка «Дружба» — исходники

Исходная копия сайта и сервер расширенного оформления: общий выбор вещей, размеры ковров, желаемый вывоз и способы оплаты.

[Демонстрация для клиента](https://piertotum1ocomotor.github.io/druzhba-dry-cleaning/order/). Ветка `main` содержит статическую демонстрацию GitHub Pages; эта ветка `source` — исходники для отдельного хостинга.

Запуск из корня ветки `source` с Python 3.11+: `python3 _server/server.py --www . --port 8080`. Т-Банк и CRM по умолчанию выключены. Реквизиты терминалов, пароли, закрытые интеграции, база и история заявок исключены. Настройки вносите через закрытое окружение по `_server/.env.example`.

Сборка демонстрации: `python3 _tools/build_pages_demo.py dist`. Pages публикуется из ветки `main`, поэтому публиковать нужно содержимое `dist`, а не серверные файлы. В демонстрации заявки не отправляются и деньги не списываются. Исходные страницы и аналитические коды сохранены.
