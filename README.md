# Химчистка «Дружба»

Исходная копия сайта и расширенное оформление: общий выбор вещей, размеры ковров, желаемый вывоз и способы оплаты.

[Демонстрация оформления](https://piertotum1ocomotor.github.io/druzhba-dry-cleaning/order/).

GitHub Pages показывает демонстрацию: заявки не отправляются и деньги не списываются. Исходные страницы и аналитические коды сохранены в корне. Автоматическая сборка добавляет новый интерфейс и блокировку отправки только в публикуемый артефакт; исходники для сервера остаются отдельными от демонстрационных изменений.

Сервер: `_server/`. Запуск из корня репозитория с Python 3.11+: `python3 _server/server.py --www . --port 8080`. По умолчанию Т-Банк и CRM выключены. Реквизиты терминалов, пароли, закрытые интеграции, база и история заявок в репозиторий не включены. Настройки вносите через закрытое окружение по `_server/.env.example`.

Сборка демонстрации: `python3 _tools/build_pages_demo.py dist`. Публикация выполняется workflow `.github/workflows/pages.yml`.
