# Химчистка «Дружба» — демонстрация

[Открыть обновлённое оформление заказа](https://piertotum1ocomotor.github.io/druzhba-dry-cleaning/order/).

Статическая версия для показа клиенту: выбор вещей, размеры ковров, желаемый вывоз и способы оплаты. В демонстрации заявки не отправляются и деньги не списываются.

[Исходники сервера для отдельного хостинга находятся в ветке source](https://github.com/Piertotum1ocomotor/druzhba-dry-cleaning/tree/source). Там же находятся исходная копия сайта, каталог, настройки форм без секретов и инструмент сборки демонстрации. Ключи, пароли, базы и история заявок в репозиторий не включены.
